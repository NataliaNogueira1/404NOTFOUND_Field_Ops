# Gestão do Projeto — FieldOps

Artefatos do **Projeto FieldOps** produzidos para a disciplina de Gestão de
Projetos. O diretório reúne planejamento, custos, qualidade, recursos,
comunicações, riscos, estrutura do trabalho e os documentos do Relatório Final.
Os diagramas em Mermaid são renderizáveis diretamente no GitHub.
